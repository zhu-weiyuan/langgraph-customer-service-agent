# 开放平台与开发者指南

## 开放平台简介

智联开放平台(open.smartlinktech.com)面向云服务专业版用户与企业合作伙伴,提供设备状态查询、设备控制、场景触发、事件订阅(Webhook)等 REST API,可将智联设备接入第三方系统(智慧酒店、办公楼宇、自研 App 等)。开通条件:云服务专业版订阅(¥38/月或 ¥380/年);企业合作伙伴可申请独立商务通道(b2b@smartlinktech.com)。个人免费版/家庭版用户无 API 权限,调用会返回 403。

## 开发者账号与应用创建

使用智联账号登录 open.smartlinktech.com→"控制台"→"创建应用",填写应用名称、用途说明,即时获得 AppKey 与 AppSecret(Secret 仅创建时展示一次,丢失需重置)。每个账号最多创建 5 个应用。应用默认拥有本账号名下设备的读写权限;如需访问其他用户设备(平台型应用),须走 OAuth 授权流程并通过企业资质审核(5-10 个工作日)。

## API 认证方式

采用 OAuth 2.0 client_credentials 模式:以 AppKey/AppSecret 调用 `POST /v1/oauth/token` 换取 access_token,有效期 2 小时;refresh_token 有效期 30 天。所有业务接口在 Header 携带 `Authorization: Bearer {access_token}`。token 过期返回 401,请实现自动刷新而非每次请求都取新 token(取 token 接口有独立限流 60 次/小时)。AppSecret 泄露请立即在控制台重置,旧 Secret 即时失效。

## API 配额与限流

专业版默认配额:每日 10,000 次调用、QPS 上限 10。超出返回 429 与错误码 E047,当日配额次日 0 点(东八区)重置。控制台"用量"页可查小时级调用曲线与配额余量,用量达 80% 时邮件提醒。提额:控制台提交提额申请(说明场景与预估量),审核 2 个工作日;企业合作伙伴可按合同定制配额。最佳实践:状态类需求优先用 Webhook 事件推送替代轮询,可节省 90% 以上调用量。

## 核心 API 一览

- `GET /v1/devices`:设备列表(分页,每页最大 100)
- `GET /v1/devices/{id}/status`:单设备实时状态(在线状态、开关、亮度、温湿度读数等)
- `POST /v1/devices/{id}/commands`:下发控制指令(开关、亮度、色温、窗帘开合度)
- `POST /v1/scenes/{id}/trigger`:触发已创建的场景
- `GET /v1/events`:历史事件查询(最长回溯 90 天,与专业版回放期一致)
- `POST /v1/webhooks`:注册事件回调
所有接口基于 HTTPS,请求与响应均为 JSON,时间戳统一 ISO 8601 东八区。完整字段说明见控制台内 API 文档。

## Webhook 事件订阅

在控制台或 `POST /v1/webhooks` 注册回调地址,可订阅事件类型:设备上下线、开关状态变化、传感器触发(门窗/人体)、告警(过载 E018、低电量 E017)、固件更新完成。要求:回调地址必须是公网可达的 HTTPS,收到推送后 3 秒内返回 HTTP 200。失败重试 3 次,间隔 1/5/30 分钟;连续失败 24 小时后该 Webhook 自动暂停(错误码 E048),需在控制台手动恢复。单应用最多注册 10 个 Webhook。

## Webhook 签名校验

每次推送 Header 携带 `X-SmartLink-Signature`,算法:HMAC-SHA256(AppSecret, timestamp + "." + rawBody) 的十六进制小写。校验步骤:1) 取 Header 中 `X-SmartLink-Timestamp`;2) 本地计算签名并与 Header 比对;3) 拒绝时间偏差超过 300 秒的请求(防重放)。常见错误:用解析后重新序列化的 JSON 计算签名(字段顺序变化导致不匹配),务必用原始请求体 rawBody。测试工具:控制台"Webhook 调试"可发送带合法签名的测试事件。

## 沙箱环境

沙箱地址 sandbox-open.smartlinktech.com,提供 20 台虚拟设备(音箱、灯泡、插座、各类传感器),可模拟状态变化与事件推送,不产生真实设备动作,不计入生产配额(沙箱独立限流 QPS 5)。AppKey 在生产与沙箱通用,仅域名不同。建议集成流程:沙箱联调→小流量灰度(真实设备)→全量。沙箱数据每周日 24:00 重置。

## 常见集成问题:401/403

- 401 Unauthorized:token 过期(2 小时)或格式错误;确认 Header 为 `Bearer {token}`,并实现过期自动刷新
- 403 Forbidden 常见三种:a) 账号非专业版订阅(会员到期自动降级也会触发,检查"会员中心");b) 访问了非本账号设备且未完成 OAuth 授权;c) 应用被禁用(违规或长期未用,控制台可见状态)
- 排查顺序:先在控制台"API 调试"用同一 token 调 `GET /v1/devices`,能通则问题在业务代码,不能通则看应用与订阅状态

## 常见集成问题:指令下发无效果

`POST /v1/devices/{id}/commands` 返回 200 但设备无动作:1) 200 仅表示指令受理,实际结果以设备状态事件为准,离线设备指令会缓存 60 秒后丢弃——先查 `/status` 中 online 字段;2) Zigbee 子设备经网关转发,网关离线(E011)时全部子设备不可控;3) 指令参数越界(亮度 1-100、色温 2700-6500)会被静默钳制到边界值;4) 窗帘电机未做行程校准会拒绝动作(E020)。建议订阅状态变化事件做闭环确认。

## 常见集成问题:事件延迟与丢失

正常情况下事件从设备触发到 Webhook 送达小于 2 秒。延迟高排查:1) 回调服务响应慢(必须 3 秒内返回 200,业务逻辑请异步处理);2) 重试队列堆积(前序失败事件按 1/5/30 分钟重试,阻塞后续)。事件不保证严格有序,请按 payload 中 event_time 排序;至少一次(at-least-once)投递,消费端需按 event_id 幂等去重。传感器类事件有 5 秒合并窗口(同一传感器连续触发合并上报),属预期行为。

## API 错误码对照

开放平台业务错误在响应体 code 字段返回,与设备错误码(E0xx)体系独立:

| HTTP | code | 含义 | 处理 |
|------|------|------|------|
| 401 | 10001 | token 无效/过期 | 刷新 token |
| 403 | 10003 | 无权限/非专业版 | 检查订阅与授权 |
| 404 | 10004 | 设备不存在或已解绑 | 重新拉取设备列表 |
| 422 | 10022 | 参数校验失败 | 见 message 字段 |
| 429 | 10029 | 配额/QPS 超限(E047) | 退避重试、申请提额 |
| 503 | 10050 | 服务维护 | 看 status.smartlinktech.com |

## 开发者支持与合规

- 技术支持:开放平台控制台工单(专业版用户 1 个工作日内响应)、开发者邮箱 dev@smartlinktech.com;工单请附 request_id(每个响应 Header 均返回)
- 文档与变更:API 变更提前 30 天在控制台公告,废弃接口保留至少 6 个月过渡期
- 合规要求:通过 API 获取的用户数据仅限授权用途,禁止转售;摄像头视频流接口仅对签约企业开放
- 服务可用性:开放平台随云服务承诺 SLA 99.9%,维护窗口提前 48 小时公告

## 专业版到期对 API 的影响

专业版订阅到期未续费的次日起,API 调用统一返回 403(code 10003),已注册的 Webhook 暂停推送但配置保留 90 天;90 天内续费即自动恢复,无需重新集成。生产环境请开启自动续费并监控 403 比例,避免业务中断。退订专业版按剩余天数比例退款(见《计费与发票说明》),退订当日 API 权限即终止。

## API 数据范围与限制说明

可读写:设备开关/亮度/色温/窗帘开合度、传感器读数、场景触发、事件历史(回溯 90 天)。不开放:语音对话内容、用户账号资料、支付信息;摄像头视频流仅签约企业可用。设备列表分页每页最大 100 条;历史事件单次查询窗口最长 7 天,更长区间请分段拉取。
