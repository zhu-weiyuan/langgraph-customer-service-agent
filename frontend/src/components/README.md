# frontend/src/components/

- ChatInput.vue：输入、发送和快捷建议。
- MessageList.vue：消息列表和流式中间态。
- SessionSidebar.vue：会话列表、搜索、切换、新建。
- AnalyticsPanel.vue：观测/分析展示。
- MemoryPanel.vue：长期记忆查看和删除。
- MessageFeedback.vue：星级、表情和评价。
- SourceChips.vue：RAG 来源展示。
- StatusBar.vue：连接、模型和运行状态。
- LoginModal.vue、ToastStack.vue：登录和提示。
